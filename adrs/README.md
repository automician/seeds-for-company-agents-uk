# Рішення про архітектуру (ADR)

ADR (запис архітектурного рішення) — одне рішення про те, як влаштовано місто, в
одному файлі: що вирішили, чому і що з цього випливає.

- Ім'я файлу — `ADR-<три цифри>-<назва-англійською>.md`, наприклад
  `ADR-001-department-repos.md`.
- Шапка: статус (пропоновано / прийнято / прийнято як робоча гіпотеза, з
  подією-перевіркою / замінено на ADR-…) і дата.
- Розділи: Контекст, Рішення, Наслідки, Відкрито.
- `ADR-000` — рішення, з якого починається проєкт: як влаштовано місто і чому.
- Новий ADR — коли людина вирішує змінити конституцію, маршрути даних чи склад
  ядра (не кожна правка файлу): чернетку готує агент, приймає людина.
- ADR не редагують заднім числом: нове рішення — новий файл, а старому міняють
  лише статус на «замінено на ADR-…».
